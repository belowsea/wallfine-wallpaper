# 问题反馈与功能建议

请通过 [Issue 模板](https://github.com/belowsea/wallfine-wallpaper/issues/new/choose) 提交，先搜索是否已有相同问题。

## 问题反馈请包含

- Wallfine 版本号，以及安装包来自 GitHub 还是官网。
- Windows 版本、屏幕数量与缩放比例；音乐问题注明播放器及版本。
- 从什么页面开始、按什么顺序操作、期望结果和实际结果。
- 是否每次发生，是否能在重启后复现。
- 最小必要的错误文字、截图或短录屏。

请不要公开 API 密钥、登录令牌、配对 token、有效连接码、账号资料、私人文件名或完整文件路径。局域网截图中的地址也建议遮去。不要直接上传整个应用数据目录或未审查的日志压缩包。

## 功能建议

描述你想完成的任务、现在遇到的阻碍，以及希望的交互方式。参考图可以帮助说明，但请确认你有权分享。

本仓库不接受应用源码 Pull Request，也不承诺具体功能排期。公开 Issue 适合普通问题；账号隐私、支付和安全问题请通过 [官网联系方式](https://www.wallfine.cn) 私下联系。
