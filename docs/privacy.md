# 客户端隐私说明

更新日期：2026-11-06。本文描述当前客户端的主要数据路径，不代表“完全不联网”或“零数据收集”。官网账户服务与第三方服务还适用各自公布的规则。

## 联网与账户

壁纸浏览、搜索、收藏、资源授权、登录和检查更新会与 Wallfine 官网及实际图源通信。客户端使用安装标识与客户端会话；设备登记可包含设备名称、系统版本、应用版本和首次启动时间，启动、账户变化与周期心跳会同步相应状态。

在官网接口提供相关能力时，客户端会上报下载、更新等必要操作的阶段、时间、版本和关联标识，用于状态确认及故障排查。它不是将全部桌面活动或所有操作内容发送到服务器。

登录 access token 主要在内存使用，refresh token 使用 Windows 凭据管理器保存。公开反馈中不要提交任何令牌或账户凭据。

## 本地图片与桌面能力

导入本地图片时登记原文件，不因导入自动上传或移动。移除图库登记不会删除原图。主动下载、临时缓存、壁纸副本和使用记录各有本地用途；删除软件不应被理解为自动删除所有自行下载的文件。

用户主动选择“找相似”或发送 AI 附件等联网功能时，相关参考缩略图、输入或附件会按该功能的请求发送，不能把普通本地导入不上传理解为任何场景都不传图片。

## 桌面组件与通知

开启组件后，会按功能使用系统媒体会话、硬件/网络状态、应用入口或系统通知等本地能力。灵动岛不读取聊天数据库；通知正文需单独开启，仅在本地内存按有界生命周期保留。关闭或锁屏时按组件规则清理。系统 Toast、托盘和任务栏提醒的来源与能力不同。

## 局域网传输

仅显式选择的电脑文件可供其他设备下载；文字与链接仅在明确发送后共享，不自动读取剪贴板、不自动打开收到的链接。当前会话文字不写磁盘或日志，刷新连接、停用或退出后清除；已经被其他设备复制的内容无法撤回。

传输首版使用 HTTP，请仅在可信局域网使用。链接、连接码与已配对设备具有当前会话访问意义，不要公开分享有效连接信息。

启动器会按你启用的来源在本机建立搜索索引，可能涉及应用、文件或浏览器历史；请仅开启需要的来源。将搜索内容交给 AI 仍取决于对应的显式操作与配置。

## 可选 AI

模型配置、对话与历史按客户端功能保存在本机。使用 AI 时，输入、附件和必要上下文会发送到你选择的模型服务。不同服务商的数据保留和费用规则不同，请自行查看对应说明，不要发送不希望交给该服务的敏感信息。

## 管理与联系

可以关闭不需要的组件、关闭通知正文、解除账户绑定，并通过历史或文件管理入口清理对应本地内容。涉及官网账户资料和服务器数据的问题，请通过 [官网联系方式](https://www.wallfine.cn) 联系；不要将隐私请求内容发布到公开 Issue。
