# 安装与常见问题

## 获取安装包

仅从 [本仓库 Releases](https://github.com/belowsea/wallfine-wallpaper/releases/latest) 或 [官网](https://www.wallfine.cn) 获取安装包。选择名称以 `x64-Setup.exe` 结尾的文件；GitHub 的 Source code ZIP/TAR 是展示仓库快照，不能安装。

应用面向 Windows x64。当前主要验证环境为 Windows 11；不宣称所有 Windows 版本、显卡驱动、混合缩放和播放器均已验证。macOS、Linux 与 Windows ARM64 原生版本目前不在本仓库发布范围内。

需要 Microsoft Edge WebView2 Runtime。安装包提供联网补装引导，首次安装缺少运行时时请保持网络可用；这不是包含完整运行时的纯离线安装包。

## 安装或升级

1. 保存正在进行的任务，从 Windows 系统托盘退出旧版 Wallfine。
2. 运行正式安装包，按安装向导完成安装。
3. 启动应用，检查“关于/检查更新”中的版本号，再按需登录和开启组件。

通常可覆盖安装。升级前建议备份重要的自定义配置；不要为了排查问题直接删除原文件、下载目录或所有应用数据。GitHub 发布和官网应用内更新服务独立，二者提示时间可能不同。

## 核对安装包完整性

下载 Release 中的 `SHA256SUMS.txt`，在 PowerShell 中运行：

```powershell
Get-FileHash .\Wallfine-1.0.4-x64-Setup.exe -Algorithm SHA256
```

把输出与校验文件中同名文件的 SHA256 对照。散列一致只说明文件与发布字节一致，不替代对下载来源的判断。

`.exe.sig` 是 Tauri 更新校验签名，不是 Windows Authenticode 发行者证书。遇到 Windows 的未知发行者或安全提示时，先核对来源与散列；不要关闭系统整体防护来安装。

## 常见问题

**组件不能启动？** 桌面组件与自动更换登录后免费使用，请先确认账户已登录；退出或会话失效时组件会暂停并保留配置。

**音乐没有显示或不能拖动进度？** 需要播放器向 Windows 提供媒体会话。优先尝试正常开始播放，在灵动岛设置中启用音乐并选择播放器。没有封面、时长或控制能力时会降级显示；不是所有音乐软件、网页或同应用多窗口都能提供相同能力。

**如何调整灵动岛位置？** 在组件设置中取消“锁定位置”，使用移动手柄拖动，或选择位置预设、自由位置百分比。完成后重新锁定。找不到组件时使用“恢复默认位置”。只有顶部居中且锁定时使用贴顶收纳。

**局域网设备连不上？** 两端需要处于同一可信 Wi-Fi/局域网，避开访客网络隔离。核对所选网卡、连接码和 Windows 私有网络访问许可；刷新连接后重新扫码。应用不会自动修改防火墙。当前使用 HTTP，不适合公共、不可信网络。

**锁屏设置失败？** Windows 版本、策略或系统接口可能拒绝修改。请保留错误信息，通过 Windows 锁屏设置手动处理，不需要修改系统安全策略。

**为什么普通更新也会弹窗？** 检测到普通新版时可以选择“稍后更新”；需要更新的版本则不能跳过。具体最低支持版本和发布状态由官网版本服务决定。

仍有问题请按 [反馈指南](feedback.md) 提供版本、系统环境、复现步骤及脱敏截图。
